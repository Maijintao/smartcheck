> 制定日期：2026-06-01

## 一、概述

### 1.1 背景

省平台要求晨检仪通过 SM4 国密加密方式对接，所有 POST/PUT/PATCH 请求体需加密，JSON 响应需解密。本计划基于现有系统架构，制定从**SM4 加解密实现**到**完整业务对接**的分步实施方案。

### 1.2 核心约束

| 约束项 | 说明 |
|--------|------|
| 加密算法 | SM4-CBC，零字节填充 |
| 请求加密 | POST/PUT/PATCH 请求体必须 SM4 加密 |
| 响应解密 | 所有 JSON 响应必须 SM4 解密 |
| GET 请求 | 不加密请求体，响应仍需解密 |
| 认证方式 | Header `Token` + `SmKeys` |
| 设备标识 | `instrumentNumber`（设备 SN） |

### 1.3 用户确认需求

- **上传目标**：省平台**替代**现有平台上传功能（仅上传到省平台）
- **人员管理**：保留本地员工管理，同时支持从省平台同步排班人员

## 二、技术方案

### 2.1 SM4 加解密实现

#### 选型：BouncyCastle

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| BouncyCastle `bcprov-jdk15to18` | 成熟稳定，API 完善 | 包体积约 3.5MB | ✅ **选用** |
| 轻量级纯 Java SM4 | 体积小 | 需自行验证正确性 | ❌ 不推荐 |
| 自研 JNI + OpenSSL | 性能最优 | 维护成本高 | ❌ 不推荐 |

**Gradle 依赖：**
```kotlin
implementation("org.bouncycastle:bcprov-jdk15to18:1.78")
```

**Android 特殊处理：**
Android 系统自带旧版本 BouncyCastle Provider（名为 `"BC"`），必须先移除再注册新版本：

```kotlin
// App.kt 或初始化时
Security.removeProvider("BC")
Security.insertProviderAt(BouncyCastleProvider(), 1)
```

**零填充实现：**
BouncyCastle 默认提供 PKCS7Padding，不支持零填充。采用 `NoPadding` + 手动零填充方案：

```kotlin
// 加密：明文 → 零填充 → SM4-CBC-NoPadding → Hex
// 解密：Hex → SM4-CBC-NoPadding → 去除末尾零 → 明文
```

### 2.2 加解密流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        请求发送流程                              │
│  1. 组装请求参数为 JSON 字符串                                   │
│  2. UTF-8 编码为字节数组                                         │
│  3. 零填充至 16 的整数倍（末尾补 \x00）                          │
│  4. SM4-CBC 加密（Key + IV）                                     │
│  5. 加密结果转为 16 进制字符串                                   │
│  6. 将 Hex 字符串作为唯一请求体发送                              │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                        响应处理流程                              │
│  1. 接收响应体的 16 进制字符串                                   │
│  2. Hex 字符串转为加密字节数组                                   │
│  3. SM4-CBC 解密（Key + IV）                                     │
│  4. 去除末尾零填充                                               │
│  5. UTF-8 解码为明文字符串                                       │
│  6. JSON 反序列化为数据对象                                      │
└─────────────────────────────────────────────────────────────────┘
```

### Step 2：实现 SM4 加解密工具类

**新建文件：** `app/src/main/java/com/smartcheck/app/utils/SM4CryptoUtil.kt`

```kotlin
object SM4CryptoUtil {
    private const val ALGORITHM = "SM4"
    private const val TRANSFORMATION = "SM4/CBC/NoPadding"
    
    /**
     * SM4 加密
     * @param plaintext 明文 JSON 字符串
     * @param key 16 字节密钥
     * @param iv 16 字节初始向量
     * @return 16 进制密文字符串
     */
    fun encrypt(plaintext: String, key: ByteArray, iv: ByteArray): String {
        // 1. UTF-8 编码
        val plainBytes = plaintext.toByteArray(Charsets.UTF_8)
        // 2. 零填充至 16 的整数倍
        val paddedBytes = zeroPadding(plainBytes)
        // 3. SM4-CBC 加密
        val cipher = Cipher.getInstance(TRANSFORMATION, "BC")
        cipher.init(Cipher.ENCRYPT_MODE, SecretKeySpec(key, ALGORITHM), IvParameterSpec(iv))
        val encrypted = cipher.doFinal(paddedBytes)
        // 4. 转 16 进制
        return encrypted.toHex()
    }
    
    /**
     * SM4 解密
     * @param ciphertext 16 进制密文字符串
     * @param key 16 字节密钥
     * @param iv 16 字节初始向量
     * @return 明文 JSON 字符串
     */
    fun decrypt(ciphertext: String, key: ByteArray, iv: ByteArray): String {
        // 1. 16 进制转字节
        val encryptedBytes = ciphertext.hexToBytes()
        // 2. SM4-CBC 解密
        val cipher = Cipher.getInstance(TRANSFORMATION, "BC")
        cipher.init(Cipher.DECRYPT_MODE, SecretKeySpec(key, ALGORITHM), IvParameterSpec(iv))
        val decrypted = cipher.doFinal(encryptedBytes)
        // 3. 去除零填充
        val plainBytes = removeZeroPadding(decrypted)
        // 4. UTF-8 解码
        return String(plainBytes, Charsets.UTF_8)
    }
    
    private fun zeroPadding(data: ByteArray): ByteArray {
        val blockSize = 16
        val paddingLen = blockSize - (data.size % blockSize)
        if (paddingLen == blockSize) return data // 刚好整除，无需填充
        return data + ByteArray(paddingLen) { 0 }
    }
    
    private fun removeZeroPadding(data: ByteArray): ByteArray {
        var len = data.size
        while (len > 0 && data[len - 1] == 0.toByte()) {
            len--
        }
        return data.copyOf(len)
    }
    
    private fun ByteArray.toHex(): String = joinToString("") { "%02x".format(it) }
    
    private fun String.hexToBytes(): ByteArray {
        val len = length
        val data = ByteArray(len / 2)
        var i = 0
        while (i < len) {
            data[i / 2] = ((Character.digit(this[i], 16) shl 4) +
                    Character.digit(this[i + 1], 16)).toByte()
            i += 2
        }
        return data
    }
}
```

### Step 5：实现省平台 API 客户端

**新建文件：** `app/src/main/java/com/smartcheck/app/api/ProvincePlatformService.kt`

核心设计：封装 HTTP 调用 + 自动加解密。

```kotlin
@Singleton
class ProvincePlatformService @Inject constructor(
    private val httpClient: HttpClient,
    private val settingsRepository: SettingsRepository,
    private val sm4Crypto: SM4CryptoUtil
) {
    // 基础配置
    private val baseUrl: String
        get() = settingsRepository.provincePlatformUrl.value.trimEnd('/')
    
    private val smKey: ByteArray
        get() = settingsRepository.provincePlatformSmKey.value.hexToBytes()
    
    private val smIv: ByteArray
        get() = settingsRepository.provincePlatformSmIv.value.hexToBytes()
    
    private val smKeysHeader: String
        get() = settingsRepository.provincePlatformSmKeysHeader.value
    
    // ========== 接口方法 ==========
    
    /**
     * 登录（POST，请求体加密）
     */
    suspend fun login(request: ProvinceLoginRequest): Result<ProvinceApiResponse<ProvinceLoginData>> {
        return postEncrypt<ProvinceLoginRequest, ProvinceApiResponse<ProvinceLoginData>>(
            path = "/api/cgibin/chenjianyi/login",
            body = request,
            token = "1" // 登录接口固定 Token
        )
    }
    
    /**
     * 获取当天排班人员（GET，请求不加密，响应加密）
     */
    suspend fun getTodayPersonSchedule(orgId: Int): Result<ProvinceApiResponse<List<ProvincePersonSchedule>>> {
        return getDecrypt<ProvinceApiResponse<List<ProvincePersonSchedule>>>(
            path = "/api/cgibin/chenjianyi/get_today_person_schedule",
            query = mapOf("orgId" to orgId.toString())
        )
    }
    
    /**
     * 新增人员（POST，请求体加密）
     */
    suspend fun addPerson(personList: List<ProvinceAddPersonRequest>): Result<ProvinceApiResponse<JsonElement>> {
        return postEncrypt<List<ProvinceAddPersonRequest>, ProvinceApiResponse<JsonElement>>(
            path = "/api/cgibin/chenjianyi/add_job_person",
            body = personList
        )
    }
    
    /**
     * 获取晨检管理项（GET，响应加密）
     */
    suspend fun getInspectionContent(orgId: Int? = null): Result<ProvinceApiResponse<List<ProvinceInspectionItem>>> {
        val query = orgId?.let { mapOf("orgId" to it.toString()) } ?: emptyMap()
        return getDecrypt<ProvinceApiResponse<List<ProvinceInspectionItem>>>(
            path = "/api/cgibin/chenjianyi/get_inspection_content",
            query = query
        )
    }
    
    /**
     * 晨检数据上传（POST，请求体加密）
     */
    suspend fun uploadMorningCheckData(dataList: List<ProvinceMorningCheckUpload>): Result<ProvinceApiResponse<JsonElement>> {
        return postEncrypt<List<ProvinceMorningCheckUpload>, ProvinceApiResponse<JsonElement>>(
            path = "/api/cgibin/chenjianyi/update_person_morning_check_data",
            body = dataList
        )
    }
    
    /**
     * 获取晨检类型（POST，请求体加密）
     */
    suspend fun getLedgerItemConfig(type: String): Result<ProvinceApiResponse<JsonElement>> {
        return postEncrypt<ProvinceLedgerConfigRequest, ProvinceApiResponse<JsonElement>>(
            path = "/api/background_fund_supervision/ledger_food_safety/get_ledger_item_config",
            body = ProvinceLedgerConfigRequest(ledger_data_type = type)
        )
    }
    
    // ========== 通用加解密请求方法 ==========
    
    /**
     * POST 请求：请求体加密，响应解密
     */
    private suspend inline fun <reified T : Any, reified R> postEncrypt(
        path: String,
        body: T,
        token: String? = null
    ): Result<R> = withContext(Dispatchers.IO) {
        try {
            val jsonBody = Json.encodeToString(body)
            val encryptedBody = sm4Crypto.encrypt(jsonBody, smKey, smIv)
            
            val authToken = token ?: settingsRepository.provincePlatformToken.value
            
            val response = httpClient.post("$baseUrl$path") {
                contentType(ContentType.Text.Plain) // 实际传的是 Hex 字符串
                header("Token", authToken)
                header("SmKeys", smKeysHeader)
                // 测试环境
                if (BuildConfig.DEBUG) {
                    header("apisix", settingsRepository.provincePlatformTestApisix.value)
                }
                setBody(encryptedBody)
            }
            
            decryptResponse<R>(response)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
    
    /**
     * GET 请求：请求不加密，响应解密
     */
    private suspend inline fun <reified R> getDecrypt(
        path: String,
        query: Map<String, String> = emptyMap()
    ): Result<R> = withContext(Dispatchers.IO) {
        try {
            val authToken = settingsRepository.provincePlatformToken.value
            
            val response = httpClient.get("$baseUrl$path") {
                contentType(ContentType.Application.Json)
                header("Token", authToken)
                header("SmKeys", smKeysHeader)
                if (BuildConfig.DEBUG) {
                    header("apisix", settingsRepository.provincePlatformTestApisix.value)
                }
                query.forEach { (k, v) -> parameter(k, v) }
            }
            
            decryptResponse<R>(response)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
    
    /**
     * 解密响应
     */
    private suspend inline fun <reified R> decryptResponse(response: HttpResponse): Result<R> {
        if (!response.status.isSuccess()) {
            return Result.failure(Exception("HTTP ${response.status}"))
        }
        
        val encryptedText = response.body<String>()
        val decryptedJson = sm4Crypto.decrypt(encryptedText, smKey, smIv)
        val result = Json.decodeFromString<R>(decryptedJson)
        return Result.success(result)
    }
}
```

```kotlin
@Singleton
class ProvincePlatformRepository @Inject constructor(
    private val service: ProvincePlatformService,
    private val settingsRepository: SettingsRepository
) {
    /**
     * 判断省平台是否已配置
     */
    val isConfigured: Boolean
        get() = settingsRepository.provincePlatformUrl.value.isNotBlank()
                && settingsRepository.provincePlatformUserId.value.isNotBlank()
                && settingsRepository.provincePlatformSmKey.value.isNotBlank()
                && settingsRepository.provincePlatformSmIv.value.isNotBlank()
    
    /**
     * 执行登录，缓存 token 和 orgId
     */
    suspend fun login(): Result<ProvinceLoginData> {
        val request = ProvinceLoginRequest(
            userId = settingsRepository.provincePlatformUserId.value,
            password = settingsRepository.provincePlatformPassword.value,
            instrumentNumber = settingsRepository.provincePlatformInstrumentNumber.value
        )
        
        return service.login(request).map { response ->
            if (response.statuCode == 200 && response.data != null) {
                // 缓存 Token 和 OrgId
                settingsRepository.setProvincePlatformToken(response.data.token)
                settingsRepository.setProvincePlatformOrgId(response.data.orgId)
                Result.success(response.data)
            } else {
                Result.failure(Exception(response.info))
            }
        }.getOrElse { Result.failure(it) }
    }
    
    /**
     * 确保已登录（Token 有效）
     */
    suspend fun ensureLogin(): Result<Unit> {
        if (settingsRepository.provincePlatformToken.value.isNotBlank()) {
            return Result.success(Unit)
        }
        return login().map { }
    }
}
```

```kotlin
class ProvincePlatformSyncUseCase @Inject constructor(
    private val service: ProvincePlatformService,
    private val repository: ProvincePlatformRepository,
    private val userRepository: UserRepository,
    private val settingsRepository: SettingsRepository
) {
    /**
     * 同步当天排班人员
     */
    suspend fun syncTodayPersonnel(): Result<Int> {
        return repository.ensureLogin().mapCatching {
            val orgId = settingsRepository.provincePlatformOrgId.value
            val response = service.getTodayPersonSchedule(orgId).getOrThrow()
            
            if (response.statuCode != 200) {
                throw Exception(response.info)
            }
            
            val personList = response.data ?: emptyList()
            
            // 与本地人员关联/更新
            var updatedCount = 0
            for (person in personList) {
                val existingUser = userRepository.findByIdCard(person.idCard)
                if (existingUser != null) {
                    // 更新已有人员信息（照片、健康证等）
                    userRepository.updateFromProvincePlatform(existingUser.id, person)
                    updatedCount++
                }
                // 新人员：不入库（晨检时通过 flowId/idCard 匹配）
                // 或可选创建本地记录
            }
            
            updatedCount
        }
    }
    
    /**
     * 同步晨检管理项
     */
    suspend fun syncInspectionItems(): Result<List<ProvinceInspectionItem>> {
        return repository.ensureLogin().mapCatching {
            val orgId = settingsRepository.provincePlatformOrgId.value
            val response = service.getInspectionContent(orgId).getOrThrow()
            
            if (response.statuCode != 200) {
                throw Exception(response.info)
            }
            
            response.data ?: emptyList()
        }
    }
}
```

## 五、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| BouncyCastle 与 Android 系统 BC 冲突 | 加解密失败 | 初始化时 `Security.removeProvider("BC")` |
| 零填充与 PKCS7Padding 混淆 | 解密失败/数据错乱 | 严格使用 `NoPadding` + 手动零填充 |
| Token 过期未处理 | 接口调用失败 | Repository 层封装自动刷新逻辑 |
| 图片 Base64 过大 | 请求体过大，上传超时 | 压缩图片或分片上传 |
| 密钥/IV 长度不符 | SM4 算法异常 | 配置保存时校验 16 字节长度 |
| 测试/正式环境切换 | apisix 头误传 | BuildConfig.DEBUG 条件控制 |
